# Customer Journey Email Style Guide

Shared design tokens for the customer journey emails and pages. Use these on every page so the journey stays visually consistent. Built in HubSpot with drag and drop modules, no raw HTML.

## Colors

| Token | Hex | Use |
|---|---|---|
| Brand purple | `#7466FF` | Headings labels, buttons, links, icons, number text |
| Accent purple | `#C15CFF` | Gradient pair with the brand purple |
| Badge background | `#EEEBFF` | Number circles, icon tiles |
| Body text | `#374151` | Paragraphs and list text |
| Heading text | `#191919` | Titles and bold lead words |
| Page background | `#F5F5F5` | Outer email background |
| Divider line | `#E5E7EB` | Section dividers |
| Muted text | `#6B7280` | Footer fine print |

## Font

- Family: sans serif. Arial in the original HTML. The HubSpot default sans serif is fine.
- HubSpot size set available: 11, 12, 14, 18, 24, 36. Do not use 36.

## Sizes by element

| Element | Size | Weight |
|---|---|---|
| Page or section title (for example Welcome to FalkorDB) | 18 | Bold |
| Body paragraph | 14 | Regular |
| Section label (for example What's next, uppercase) | 12 | Bold |
| List item text | 14 | Regular |
| Bold lead words in a list item | 14 | Bold |
| Number badge (1, 2, 3) | 14 | Bold |
| Footer fine print | 11 | Regular |

Notes:
- 24 is the next step up if a title needs to be larger.
- Section labels are uppercase with about 1px letter spacing.

## Buttons

- Primary: fill `#7466FF`, white text, rounded corners.
- Secondary: white fill, `#7466FF` border and text.

## Icons and badges

- Tint icons to the brand purple `#7466FF`.
- Number badges and icon tiles use the `#EEEBFF` background.
