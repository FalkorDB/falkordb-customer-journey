## Usage in email
The emails reference these via the jsDelivr GitHub CDN, for example:
`https://cdn.jsdelivr.net/gh/FalkorDB/falkordb-customer-journey@main/journeys/new-registrants/html/images/uc-security.png`

For maximum deliverability you can also upload them to the HubSpot File Manager and swap the src values.
